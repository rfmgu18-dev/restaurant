# 🍕 Restaurante de Promesas ✔
## ▶ Resumen
Este proyecto se basa en un restaurante de comida rápida el cual utiliza como método de preparación y entrega las promesas de JavaScript
## ▶ Características
Este proyecto posee:
**Estilo Minimalista**: Este proyecto posee un estilo bastante simple y minimalista.
**Animaciones Fluidas y Colores**: Posee animaciones bastante fluidas en los recuadros y colores llamativos
## ▶ Tecnologías Utilizadas
  | Tecnología | Función |
|:---:|:---:|
| HTML   | Estructura semántica del código |
| CSS   | Estilos, márgenes y diseño del código |
| JS   | Lógica y funcionamiento del código |
